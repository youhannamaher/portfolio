PathWise is a career guidance and educational orientation platform designed to help students discover academic paths and career opportunities that align with their personalities, interests, skills, and ambitions. The project was developed as a business-oriented digital solution combining technology, education, and personalized career exploration into a modern interactive experience.

The platform features a complete multi-step “Career DNA” assessment system where users answer questions related to interests, work styles, strengths, goals, and personal preferences. Based on the responses, the system generates personalized academic and career recommendations tailored to each student profile.

The project was built as a real MVP (Minimum Viable Product) with a fully designed user journey including landing pages, authentication flows, dashboard experience, assessment process, recommendation engine, and program exploration pages. The interface was carefully designed using modern UI/UX principles with responsive layouts, glassmorphism-inspired visuals, animations, and smooth interactions to create a professional and engaging experience for students.

PathWise was not only a technical project but also a complete entrepreneurial and business model initiative. The project included market positioning, value proposition design, business strategy, MVP presentation, and a full startup-oriented pitch experience. The platform demonstrates how digital tools and intelligent profiling systems can simplify educational orientation and help students make more informed academic and career decisions.

The solution was developed using modern web technologies including Next.js, TypeScript, Tailwind CSS, and Framer Motion, with deployment and scalability considerations integrated into the project vision from the beginning.
